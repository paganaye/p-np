# A notation for graph signatures

The page already produces a canonical graph6. That string is exact and opaque: it
tells you *that* two graphs are the same, never *why*. This note fixes the shape of
a different object — a **sentence** — and the rules that keep it honest.

## 1. The object is a derivation, not a description

A sentence is the trace of the sort: for each pass, the class it attacked, the ring
it looked at, the class sizes it produced, and the pins it was forced to make. It is
not a coding of the graph; it is the reason the canonical order came out as it did.

That distinction is what makes the sentence useful. graph6 says "these 153 bits";
the sentence says "this graph is five copies of one object", and *that* is what can
be pruned.

## 2. What a production has to satisfy

A family may be written as a production only if all four hold. Otherwise the
notation degenerates into prose.

1. **Local recognizer** — a predicate on the graph, cheap compared to the search
   (typically `O(n²)` or worse by a small constant, never exponential).
2. **Closed form for the order** — the canonical order of a graph in the family is
   given by the production, with no branching.
3. **Closed form for the string** — the canonical graph6 follows from the same data.
4. **A reason** — a one-line argument that the order is invariant: why two graphs
   matching the production are isomorphic exactly when the sentence is the same.

A production is a *theorem*, not a heuristic. If the reason is missing, the sentence
is decoration.

## 3. The grammar so far

```
Graph  := Union
Union  := Part ( "⊕" Part )*        -- one term per connected component
Part   := K⟨a₁…a_k⟩ | …             -- complete multipartite
```

`K⟨a₁…a_k⟩` is the complete multipartite graph with parts of those sizes. It covers:

| graph | sentence |
|---|---|
| `K_n` | `K⟨1×n⟩` |
| empty graph | `K⟨n⟩` |
| `K_{a,b}` | `K⟨a,b⟩` |
| Turán graph `T(n,r)` | `K⟨…⟩` with `r` parts |
| `K_n` minus a perfect matching | `K⟨2×n/2⟩` |

The last line is the graph that used to cost more than 1000 branches; it now costs
one.

## 4. Orthography

Sizes inside a part list are non-increasing; repeated parts are compressed
(`K⟨2×5⟩`, not `K⟨2,2,2,2,2⟩`); `⊕` binds tighter than nothing and is written left
to right in the order the sort produced. Equal-sized parts are interchangeable, so
their relative order in the sentence carries no information and the canonical string
does not move.

## 5. What a family is

A family is the set of graphs generated by one production, with the parameters free.
"It is a union of complete multipartite graphs" is a family; the sentence shape
`K⟨…⟩ (⊕ K⟨…⟩)*` is its language.

## 6. The falsifiable question

If this is worth doing, the sentences of the families we meet must be **periodic**:
`C_n` should read as one period repeated, `P_n` as a prefix and a suffix with a
repeated middle, `K⟨2×n/2⟩` as a single word.

- If they are periodic, the grammar is real, and parsing a prefix is the pruning.
- If they are not, no grammar will fall out, and what remains is a library of
  ad-hoc productions — useful, but not a language.

The first experiment is therefore cheap and decisive: print the sentence of
`C_n`, `P_n`, `K⟨2×n/2⟩`, and two random graphs for `n = 6…12`, and look at whether
a period appears. No implementation is needed beyond the log the page already
writes.
