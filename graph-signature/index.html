                    The signature is a sort, and its key is a walk tree: from a
                    vertex, follow every path and mark a branch that comes back to one of its own
                    ancestors, with the distance it took. Counting neighbours cannot tell a triangle
                    from a square, but at depth 3 the triangle's tree already shows a
                    ^3 return and the square's does not — that is the whole point.
                    Pass p looks p rings deep, and every node of the tree carries
                    the position of its group. When the keys separate nothing, the sort goes one
                    ring deeper — that is how a square and a triangle, both 2-regular, are finally
                    told apart. When the depth is spent and a group still refuses to split, the
                    search pins each of its members in turn and keeps the smallest graph6, so the
                    result is a comparison, not a choice. The A…R labels never enter a
                    key; they only make the log readable. A group of one vertex is
                    frozen, a set of interchangeable vertices is
                    twins (their order cannot change the matrix), the rest is
                    tied. Shuffle labels renumbers the vertices without
                    touching a single edge — the input graph6 changes, the canonical one must not.
